# CAD Studio Pro

Aplicación profesional de diseño CAD/BIM con soporte para planos 2D, elevaciones 3D y visualización VR.

## 🚀 Instalación como Aplicación

Esta aplicación es una **PWA (Progressive Web App)** que puede instalarse en tu dispositivo:

### En el Navegador

1. Abre la aplicación en tu navegador web
2. Busca el icono de instalación en la barra de direcciones (⊕)
3. Haz clic en "Instalar CAD Studio Pro"
4. La aplicación se instalará en tu sistema

### Después de Instalar

- **Windows**: Busca "CAD Studio Pro" en el menú Inicio o buscador de Windows
- **macOS**: Busca "CAD Studio Pro" en Spotlight (Cmd + Espacio)
- **Linux**: Busca en el menú de aplicaciones o lanzador

### Ventajas de la Instalación

✅ **Acceso rápido** - Abre la app directamente desde tu escritorio  
✅ **Búsqueda por nombre** - Encuentra "CAD Studio" en el buscador de tu sistema  
✅ **Funciona sin internet** - Una vez instalada, funciona offline  
✅ **Experiencia nativa** - Se siente como una aplicación de escritorio  

## 🛠️ Características

- **Modo 2D**: Diseño de planos arquitectónicos con herramientas CAD
- **Modo 3D**: Elevaciones y modelado tridimensional
- **Modo VR**: Visualización inmersiva de proyectos
- **PDF Overlay**: Importa y edita sobre documentos PDF
- **Coordenadas Ortogonales**: Sistema de coordenadas infinito
- **Símbolo de Norte**: Orientación geográfica
- **Comandos de Voz**: Control por voz con Ctrl + Mic
- **Exportación Múltiple**: .DWG, .RVT, .PDF, .TIF

## 📖 Cómo Usar

### Desde Index (Sin Instalación)

Simplemente abre `index.html` en tu navegador y la aplicación funcionará inmediatamente.

### Como Aplicación Instalada

1. Instala siguiendo los pasos anteriores
2. Busca "CAD Studio" en tu sistema
3. Abre la aplicación
4. ¡Empieza a diseñar!

## 🎨 Herramientas Disponibles

### Modo 2D
- Seleccionar, Línea, Rectángulo, Círculo
- Mover, Copiar, Rotar
- Capas, Terreno, Documentos

### Modo 3D
- Seleccionar, Extruir, Pared
- Cortar, Mover 3D, Rotar
- Curvar Pared, Puntos Guía

## 💡 Atajos de Teclado

- `Ctrl + Mic`: Activar comandos de voz
- Clic en herramientas para seleccionar
- Arrastrar en canvas para dibujar
