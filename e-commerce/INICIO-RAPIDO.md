# ⚡ INICIO RÁPIDO - Alena E-commerce

## 🪟 Para Windows (RECOMENDADO)

### 3 pasos simples:

#### 1️⃣ Instalar
Haz doble clic en: **`install.bat`**
```
⏳ Espera 2-5 minutos mientras se instalan las dependencias
```

#### 2️⃣ Iniciar
Haz doble clic en: **`start.bat`**
```
🌐 Se abrirá automáticamente en http://localhost:5173
```

#### 3️⃣ ¡Listo! 🎉
```
✅ La aplicación está funcionando
✅ Puedes cerrar el CMD cuando termines con Ctrl+C
```

---

## 🍎 Para Mac/Linux

### 3 comandos simples:

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor
npm run dev

# 3. Abrir en navegador
# http://localhost:5173
```

---

## ⚠️ IMPORTANTE

### ❌ NO HAGAS ESTO:
- ❌ Abrir `index.html` directamente en el navegador
- ❌ Cerrar la ventana CMD/Terminal mientras usas la app

### ✅ HAZ ESTO:
- ✅ Usa los archivos `.bat` en Windows
- ✅ Mantén la ventana CMD/Terminal abierta
- ✅ Usa `http://localhost:5173` en tu navegador

## 🆘 ¿Problemas?

### Error de PowerShell en Windows:
```
Solución: Usa install.bat y start.bat
```

### No funciona abriendo index.html:
```
Solución: Debes usar start.bat o npm run dev
```

### Puerto 5173 ocupado:
```
Solución: Vite automáticamente usará otro puerto (5174, 5175...)
```
