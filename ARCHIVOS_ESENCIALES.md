# 📁 ARCHIVOS ESENCIALES - SHIELD-MASTER 2026

## 🚀 PARA EJECUTAR LA APLICACIÓN

```
1. AYUDA.html                  → Guía visual (abre en navegador)
2. verificar-sistema.bat       → Verifica Node.js
3. instalar-simple.bat         → Instala dependencias
4. ejecutar-simple.bat         → Ejecuta la app
```
