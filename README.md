# 🛡️ Shield-Master 2026

Dashboard de Seguridad con estética **Cyber-Luxury** - React + Tailwind CSS

---

## ⚡ INICIO RÁPIDO

### **¿Primera vez? Empieza aquí:**

```
1. Abre: AYUDA.html (en tu navegador)
   → Guía visual completa

2. Doble clic: verificar-sistema.bat
   → Verifica Node.js

3. Doble clic: instalar-simple.bat
   → Instala dependencias (2-5 minutos)

4. Doble clic: ejecutar-simple.bat
   → Ejecuta la app → http://localhost:5173
```

## 🎯 Stack Tecnológico

- **React 18** + TypeScript
- **Vite** - Build Tool
- **Tailwind CSS v4** - Estilos
- **React Router v7** - Navegación
- **Recharts** - Gráficos
- **Motion** - Animaciones
- **Electron** - Desktop App
- **jsPDF** - Generación de PDFs
- **EmailJS** - Envío de reportes
